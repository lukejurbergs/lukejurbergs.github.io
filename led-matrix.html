The Project

This was my formal introduction to C++ applied to physical hardware. I CAD-modeled and 3D-printed a grid frame for addressable LEDs, added a diffusing sheet for soft light blending, then used the FastLED library on an Arduino UNO to control patterns synchronized to the beat of All the Stars by Kendrick Lamar and SZA.

It was one of my first times applying C++ loops and arrays outside of robotics. Handling 2D arrays mapped to a physical LED grid, timing animations to music, and managing per-pixel color states made me significantly more fluent in C++ as a language — not just a tool.
